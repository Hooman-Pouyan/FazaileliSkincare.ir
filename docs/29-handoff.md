## 4. The five gates. Never delete one to make something pass.

1. **`src/lib/design/tailwind-candidates.test.ts`** — compiles every class name
   in `src/` against the real theme. It has caught a dead utility in **four**
   separate packets, including `inset-block-0` twice. Tailwind has no
   `inset-block-*`, `inset-inline-*` or `border-inline-*`; the spellings are
   `inset-y-`, `start-`/`end-`, `border-s`/`border-e`.
2. **`src/lib/navigation/locale-prefix.test.ts`** — no file builds a locale
   prefix by hand, no component imports raw `next/navigation`. Caught a
   hand-built `/fa/` inside JSON-LD, where nobody would ever have clicked it.
3. **`src/lib/media/url.guard.test.ts`** — no file computes an image path.
   Its allowlist is empty and should stay empty.
4. **`src/components/layout/shell-offset.test.ts`** — the shell owns the rail
   offset; a screen never adds `ms-14`. This exists because the same rule,
   scoped to one screen's test, failed to stop two other screens repeating it.
5. **`src/lib/navigation/route-status.test.ts`** — a route that decides
   `notFound()` must answer 404. Added 2026-08-26 after a `loading.tsx` was
   found turning every not-found into a **200**: the Suspense boundary flushes
   the status line before the page has decided anything. Four soft-404s on
   enumerable facet URLs. A status code is invisible to typecheck, to ESLint and
   to every render test in the suite.

Plus `pnpm docs:open-items --check` in CI: the register in the ledger is

## 5. Environment realities — read before you plan anything

- **This runs in Cowork.** `mcp__remote-devices__device_bash` reaches the
  maintainer's machine through a mounted folder at `$HOME/mnt/FazaileliSkincare.ir`.
  The cloud `Bash` tool is a _different_ filesystem and cannot see the repo.
- **Whether you can run the database depends on where you are running.**
  This section originally said you cannot, and that described _Cowork_ — a
  sandboxed VM with the repo on a mount, no Docker and no network. A session
  running **on the maintainer's machine** has Postgres, a dev server and a
  browser, and should use all three: packets 6, 7B and 8 were only closed
  because someone could. Check before you assume.

  If you are in the sandbox: `pnpm typecheck`, `pnpm lint` and `pnpm test:unit`
  run; the integration suite does not. The method is then write it, run
  everything you can, hand the maintainer one command, read what he pastes back.
  That loop caught three real defects. **A browser pass and a `curl` of a real
  response find things no unit test can** — the soft-404s, the `Accept-Language`
  redirect and a raw object key in every image `src` were all found that way.

- **The mount refuses deletion.** `rm` fails with `Operation not permitted`.
  Use `mv` into `.git/_agent-quarantine/`. Files there are outside git's index
  and excluded from vitest, but they are still on his disk.
- **Git needs a lock dance.** Before every git write:
  ```bash
  for f in index.lock HEAD.lock; do
    [ -f ".git/$f" ] && mv ".git/$f" ".git/_agent-quarantine/$f.$(date +%s%N)"
  done
  ```
  Commit with `git -c user.name="Hooman Pouyan" -c user.email="mhooman.pouya@gmail.com"`
  — the repo has no identity configured and the history uses that one.
- **`.github/workflows/tests.yml`** runs the integration suite against
  `postgres:16` on push. That is where the SQL actually gets proven.

## 6. The maintainer's standing instructions

These are not preferences. He has restated each of them more than once.

1. **No drift.** One mechanism per concern. Tailwind on the token layer with
   shadcn primitives; Swiper is the only carousel; anime.js owns choreography
   and CSS owns state changes; navigation is one manifest. Do not add a second
   way to do something that already has a way.
2. **No hand-rolling.** Before building any UI, look in `src/components/ui`,
   then the design-system handoff library at
   `design-system/Fazaieli Design System-handoff.zip` (228 files, a `.prompt.md`
   beside every component), then shadcn and its ecosystem. `DS-1` exists because
   this was skipped once and a price filter got built from number inputs while
   the system's own `Slider` sat unused.
3. **Broadcast before adopting.** An architectural improvement is proposed,
   agreed, documented in `docs/`, _then_ built. This applies in reverse too: a
   refusal that stops being a refusal gets written down (see `E-1`).
4. **Capture everything.** Every input, redirection, refinement and decision
   goes into a decision doc, a plan doc or the review log. He has asked for this
   in almost every message. The review log is where judgements made on thin
   evidence go; the register in the ledger is generated from it.
5. **SEO is a first-class requirement**, not a later pass. Server-rendered
   Persian listings are the competitive argument.
6. **Never invent a fact about the business.** Prices, consent, credentials,
   claims, dates, addresses — all his. Leave the field empty and log it.

## 8. Traps that have already caught someone

- **Check whose the uncommitted work is before you commit it.** In the
  2026-08-26 session a favicon set, `logo.tsx` and rail/footer edits sat unstaged
  because they were not that session's; they were properly landed later in
  `4771e15`. The tree currently carries the **cart**, in flight — nineteen files
  under `src/modules/cart/`, migration `0007`, and TanStack Query and Zustand
  newly installed. Do not sweep it into an unrelated commit, and see the ledger's
  _Known bound — the cart is in flight_ for the gate it still owes.
- **`str.replace` on a non-matching string is a silent no-op.** Two edits were
  lost that way in this session because Prettier had reformatted the anchor.
  Assert the anchor exists before replacing.
- **Prettier reformats markdown tables**, so a byte-comparison of generated docs
  gives false positives, and a raw `|` inside a table cell splits it into an
  extra column and the row is silently dropped.
- **Vitest was reading `.git`** and running quarantined files. Fixed, but it
  means an earlier "336 tests green" was really 321.
- **A read that uses the wrong column is invisible to every static gate.**
  `commerce.reads` put a raw object key into every image `src` for a whole
  packet. Only real data in a real database found it.
- **`ALTER TYPE ... ADD VALUE`** is what a new content kind generates. Fine on
  PG 12+, but the value cannot be used in the same transaction that adds it.
